# ALOUTE original character stickers

Created with the built-in image generation tool for this project. The PNG has an alpha channel and is 1024 × 1536, arranged as four columns and six rows. Cells 0–7: Mèo Mỡ; 8–15: Ếch Nhỏ; 16–23: Cún Bông. The artwork does not align precisely to a uniform grid. StickerArtwork.java records measured bounds and a separate clipping polygon for each character, including detached hearts, tears and other details. Both inline SVG message rendering and the picker use these same regions. The original PNG remains unchanged.

## Generation prompt

Create a production-ready sticker sprite atlas for a Vietnamese teen chat app. Exactly 24 separate adorable hand-drawn character reaction stickers arranged in a strict 4-column by 6-row equal-cell grid on transparent background, no text, no labels, no dividers, no card backgrounds. Canvas aspect ratio 2:3. Every sticker centered within its own cell with generous transparent margin (15% padding), absolutely no overlap between cells. Crisp expressive cartoon drawing, bold dark outlines, white edge sticker cutline, soft shading, playful meme-like expressions. Original characters, do not copy existing memes. Rows 1-2: same chubby cream and gray tabby cat character in 8 poses ordered left to right: waving hello, hugging a pink heart, laughing with tears, crying dramatically, pouting crossed paws, surprised, sleepy under small blanket, studying a book. Rows 3-4: same original round sage-green frog with a tiny yellow scarf, 8 poses: wave hello, heart hug, giggling, crying, grumpy, surprised, sleepy, sipping tea. Rows 5-6: same golden-orange corgi puppy with cream cheeks, 8 poses: waving hello, holding heart, happy laugh, crying, pouting, wow surprise, sleepy, cheering with tiny confetti. All 24 characters full body where appropriate, distinct poses, large readable faces. Exact uniform grid spacing and cell sizes are critical for CSS sprite display. No writing or typography anywhere.
